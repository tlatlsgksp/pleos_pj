# Pleos SDK 확대 제안

Moli를 만들며 필요했지만 지금 외부 앱에 열려 있지 않은 기능을 정리한다. 접수 양식 7번 참고자료의 "Pleos SDK 확대 제안" 표와 2차 PT의 근거 자료로 쓰고, 기술 문의에도 쓴다.

- 작성: 2026-10-26, Moli 기준 개정 2026-11-15
- 근거: [조사 노트](PLEOS_PLATFORM_RESEARCH.md)(에뮬레이터 확인 결과는 11장), SDK 바이너리(Vehicle 2.3.2, NaviHelper 3.0.5), Pleos 문서(document.pleos.ai)
- 원칙
  - 핵심 기능은 지금 열린 API로 만든다. 이 문서의 항목은 "열리면 더 좋아지는 것"이다.
  - 항목마다 **지금의 우회 방법**과 **플랫폼이 걱정할 안전·개인정보 장치**를 함께 적는다. 제안이 받아들여지기 쉽게 하기 위해서다.
  - 특정 회사·제품 이름은 쓰지 않는다.

## 1. 요약

| 7 | 경로 안내가 없을 때의 차량 위치 | FusedLocation SDK는 "준비 중". NaviHelper `onCurrentLocationInfo`가 경로 안내 밖에서도 오는지는 문서에 없음 | 그룹 라이딩 멤버 위치 | 차 위치가 없으면 폰 위치로 대체 |
| 8 | 지난 주행 이력 | 현재 누적값만 있음. 이력 API는 유럽 한정 Vehicle Data API뿐 | 앱이 꺼져 있던 주행의 연비 랭킹 반영 | 누적 주행거리·에너지 차이로 합계만 복원 |
| 9 | 전원 ON 시 앱 화면 열기(사용자 설정) | 부팅 신호는 오지만 화면 띄우기는 시스템이 막음(`BAL_BLOCK`) | 차에 타면 홈의 내 차와 그룹 라이딩 초대 | 백그라운드 서비스 + 알림 |
| 10 | Gleo 앱 함수 등록 | App Schema 방식은 존재(내비 앱이 사용). Gleo의 `APP_ACTION` 권한이 `signature` | 음성 제보, 음성 워키토키 시작 | 앱 마이크 + 음성인식 |
| 11 | 백그라운드 동작 허용 기준 | 포그라운드 서비스는 동작함. 앱 마켓 정책상 허용 범위가 문서에 없음 | 연비 코치, 주유·충전 감지, 그룹 라이딩 위치 | 시동 시 1회 + 주기 스냅샷, 그룹 라이딩 중에만 연속 수집 |

## 2. 항목별 제안

### 2.1 차량 3D 모델 접근, 주행 화면 차량 테마

- **왜**: Moli에서는 꾸민 내 차가 곧 커뮤니티 프로필이다. 실제 차종을 닮은 모델이 있어야 꾸미기가 의미 있고, 운전자가 가장 오래 보는 주행 화면의 차에도 반영되면 생태계가 커진다.
- **제안 형태**: 차종별 경량 3D 모델과 랩 템플릿(UV 전개도)을 공개한다. 주행 화면 테마는 자유 이미지가 아니라 **랩 템플릿과 색상 팔레트 형식**으로 정하고, 앱이 그 형식의 테마 파일을 제출하면 주행 화면이 적용한다. 테마는 앱 마켓 심사를 거친다.
- **안전·브랜드 장치**: 승인된 형식만 받는다. 경고등·안내 표시 영역은 테마가 덮지 못한다. 주행 중에는 테마를 바꿀 수 없다.
- **지금의 우회**: 앱 속 3D 차량에 스킨을 입히고, 실내 무드등 색을 `setAmbientLightBrightnessColor`로 맞춘다(에뮬레이터에서 차량 HAL까지 명령 전달 확인). 탑재 차종의 앱에 쓸 수 있는 모델이 없어 경량 모델로 대신한다.

### 2.2 주행 모드·시트·스티어링 휠 위치 연동

- **왜**: "내 차가 내 프로필"을 운전 환경까지 넓힌다. 가족 차, 공유 차, 렌터카처럼 다른 Pleos 차량을 타도 내 시트·스티어링 휠 위치와 선호 주행 모드를 바로 적용한다.
- **제안 형태**: 시트 위치(앞뒤·높이·등받이), 스티어링 휠 위치(높이·거리), 주행 모드의 읽기·쓰기 API. 차량 메모리 시트 기능과 같은 값 체계를 쓴다.
- **안전 장치**: 정차(기어 P) 중에만 적용, 적용 전 운전자 확인, 운전석만.
- **지금의 우회**: 없음. 주행 모드 조회만 가능하다.

### 2.3 좌석별 전동시트 제어

- **왜**: 동승자 자리도 앱에서 조정하고, 휴게소에 정차한 동안 휴식 자세로 바꿨다가 출발 전에 되돌린다. 그룹 라이딩처럼 긴 주행에서 쓸모가 크다.
- **제안 형태**: 콘솔에 "준비 중"으로 나온 `moveSeat*`, `selectSeatMemory`를 좌석(area) 단위로 공개한다.
- **안전 장치**: 정차 중에만, 사용자 확인 후, 탑승 감지된 좌석만, 운전석은 출발 전 원래 위치로 복귀 확인.
- **지금의 우회**: 없음.

### 2.4 시동·전원 상태 이벤트

- **왜**: 주행 카드와 주행 리포트는 주행 단위로 만든다. 시작·종료를 정확히 알아야 연비 계산이 정확하다.
- **제안 형태**: SDK에 이미 있는 `IgnitionState`(LOCK/OFF/ACC/ON/START)를 읽기·구독 API로 연다.
- **안전·개인정보 장치**: 읽기 전용.
- **지금의 우회**: 기어 P→D 전환, 총 주행거리 증가, 부팅 신호를 조합한다.

### 2.5 스티어링 휠 사용자 지정 버튼

- **왜**: 주행 중 화면을 누르지 않고 워키토키를 시작할 수단이 필요하다.
- **제안 형태**: 시스템 설정에서 사용자 지정 버튼에 앱을 할당하면, 그 버튼 입력을 해당 앱에 전달한다(누름·뗌 구분 포함).
- **안전 장치**: 사용자가 할당한 앱 하나만 받는다. 다른 앱의 키 입력은 볼 수 없다.
- **지금의 우회**: 화면의 큰 [누르고 말하기] 버튼. 앱이 화면 앞에 있을 때는 미디어·통화 키도 받는다(에뮬레이터 확인).

### 2.6 내비게이션 경로 좌표

- **왜**: "현재 경로 위에 사고 제보가 있어요"와 경로상 핀·주유소 추천은 경로 선이 있어야 정확하다.
- **제안 형태**: 현재 안내 경로의 단순화한 좌표 목록(예: 500 m 간격).
- **안전 장치**: 경로 안내 중일 때만, 앱이 화면에 있거나 서비스가 실행 중일 때만.
- **지금의 우회**: 외부 길찾기로 후보마다 추가 소요 시간을 계산하고, 고른 곳을 경유지로 넣는다. 내비가 다시 계산한 시간으로 확인한다.

### 2.7 경로 안내가 없을 때의 차량 위치

- **왜**: 그룹 라이딩 멤버 위치는 목적지 없이 달릴 때도 보여야 한다.
- **제안 형태**: FusedLocation SDK 정식 공개, 또는 NaviHelper `onCurrentLocationInfo`가 경로 안내와 관계없이 온다는 것을 문서로 보장.
- **안전·개인정보 장치**: 그룹 라이딩 참여 중에만 사용, 사용자 동의, 종료 후 서버 미보관.
- **지금의 우회**: 차 위치를 받지 못하면 폰 위치로 대체한다.

### 2.8 지난 주행 이력

- **왜**: 앱을 켜지 않은 주행도 연비 랭킹과 주행 리포트에 빠짐없이 반영돼야 공정하다.
- **제안 형태**: 최근 N일의 주행(trip) 단위 요약(시작·종료 시각, 주행거리, 에너지 사용량)을 읽기 전용으로 준다. 좌표는 별도 권한으로 분리한다.
- **지금의 우회**: 누적 주행거리·에너지 차이로 합계만 복원한다.

### 2.9 전원 ON 시 앱 화면 열기

- **왜**: 차에 타자마자 홈의 내 차와 받은 그룹 라이딩 초대를 보여 주면 참여가 쉬워진다.
- **제안 형태**: 시스템 설정에 "시동 시 실행할 앱"을 두고 사용자가 고른 앱 하나만 실행한다.
- **안전 장치**: 사용자가 직접 켠 경우에만, 앱 하나만, 정차 상태에서만.
- **지금의 우회**: 부팅 시 백그라운드 서비스가 알림을 띄우고, 운전자가 알림을 눌러 연다.

### 2.10 Gleo 앱 함수 등록

- **왜**: 음성이 주행 중 가장 안전한 입력이다. "사고 제보해 줘", "그룹에 말하기" 같은 호출에 쓴다.
- **제안 형태**: App Schema 등록 절차를 외부 앱에 공개한다. 함수 개수 제한은 유지해도 된다.
- **지금의 우회**: 앱 마이크로 녹음하고 음성인식으로 처리한다.

### 2.11 백그라운드 동작 허용 기준

- **왜**: 연비 코치와 주유·충전 감지는 앱을 화면에 띄우지 않아도 동작해야 한다.
- **제안 형태**: 허용되는 백그라운드 작업 유형(예: 시동 시 1회, 15분 주기 스냅샷, 사용자가 시작한 그룹 라이딩 중 연속 위치)과 자원 한도를 문서로 정한다.
- **지금의 우회**: 시동 시 1회와 주기 스냅샷만 하고, 촘촘한 수집은 앱이 화면에 있거나 그룹 라이딩 중일 때만 한다.
