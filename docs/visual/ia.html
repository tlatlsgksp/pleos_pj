1. 메인 홈: 내 차 + 빠른 실행 결정

B안(내 차)으로 정했다. 꾸민 3D 내 차가 중심에 서 있고, 그 옆에 차에 도움이 되는 기능을 누르면 바로 실행되는 버튼으로 둔다. 다른 화면으로 넘어가지 않고 그 자리에서 끝난다.

2. 차량 앱 메뉴 (아래쪽에 떠 있는 아이콘 4개)

메뉴는 앱 화면 아래쪽 가운데에 가로로 떠 있는 반투명 막대다. 화면 영역을 차지하지 않는다. 내용이 앱 화면 전체를 쓰고, 메뉴 뒤로 지도나 3D 차가 그대로 이어지며, 글자와 버튼은 메뉴에 가리지 않는 자리에 둔다. Pleos 시스템 바(공조, 앱 목록)는 화면 맨 아래에 따로 있고, 우리 메뉴는 그 위 앱 영역 안에 뜬다. 화면 위쪽 탭과 페이지 제목 바는 쓰지 않는다. 그룹 라이딩은 늘 떠 있는 메뉴에 두지 않고, 시작은 홈의 버튼에서, 진행 중에는 떠 있는 배너로 돌아간다.

3. 이웃과 그룹 라이딩

그룹 라이딩은 이웃끼리 한다. 이웃은 서로 수락한 사이다.

단계차폰
이웃 추가나 › 이웃 › 아이디로 추가 (정차 중, 키보드)나 › 이웃 › 아이디로 추가, 커뮤니티 글쓴이 프로필에서 [이웃 요청]
요청 수락잠깐 뜨는 알림 [수락] [나중에], 나 › 이웃 › 받은 요청알림, 나 › 이웃

4. 폰 앱 메뉴

커뮤니티는 목록으로 보고, 지도로 보고 싶으면 지도 메뉴로 간다. 둘은 같은 글을 다른 방식으로 보여 준다.

글커뮤니티

목록 보기

  • 이웃 / 같은 차종 / 전체
  • 글쓰기: 사진, 태그, 위치 첨부 → 지도에 핀
  • 연비 인증 카드, 꾸미기 공유 (차에서 넘어옴)
  • 응원, 댓글, 신고
지도지도

  • 핀 = 위치 붙은 글
  • 태그로 거르기, 저장
  • 지도 표시: 주유소·충전소 가격, 진행 중인 그룹 라이딩 멤버

5. 실시간 제보

홈의 [제보]를 누르면 큰 버튼 다섯 개가 뜨고, 하나를 누르면 그 순간의 차 위치와 진행 방향으로 바로 올라간다. 입력은 없다.

종류보이는 시간다른 운전자에게
사고1시간, 다른 운전자가 "없어졌어요"를 누르면 먼저 내려감차·폰 지도의 제보 표시에 아이콘. 내 경로 위에 있으면 위에서 내려오는 배너와 짧은 음성. 지나갈 때 [아직 있어요] [없어졌어요]
공사1일
정체30분
단속카메라계속 (없어졌다는 제보가 쌓이면 내려감)
재난3시간 (침수, 낙석, 결빙 등)

내 경로 위 제보 알림

다른 운전자의 제보가 지금 안내 중인 경로 위에 있으면, 앱 화면 맨 위에서 꽉 찬 배너가 내려온다. 어느 메뉴에 있든, 메뉴가 접혀 있든 뜬다. 6초 뒤 다시 올라가고, 누르면 그 위치를 지도로 보여 준다.

주행 화면
현재 경로 위에 사고 제보가 있어요
지금 보던 화면그대로 아래에 있음

배너 앱 화면 너비 그대로, 위에서 아래로 내려옴. 종류만 바꿔 같은 문장: 공사, 정체, 단속카메라, 재난

주행 화면
제보 위치지도에 경로와 사고 아이콘, 내 차. 아래에 "3분 전 제보"와 [아직 있어요] [없어졌어요]

누르면 그 위치를 지도로 보여 준다. 확인 버튼은 그 지점을 지날 때 다시 한 번 뜬다

제보도 "위치를 붙인 글"의 한 종류다. 커뮤니티 목록에는 섞지 않고 지도와 알림에만 쓴다. 이동 중인 차만 제보할 수 있고, 위치는 차가 준 값이라 엉뚱한 곳 제보를 막는다.

6. 데이터 모델 하나로 정리

장소 핀을 따로 두지 않는다. 글 = 본문 + 사진 + 태그 + 위치(선택). 위치가 있으면 지도의 핀이 된다. 차에서 "지금 여기 핀하기"를 누르면 위치와 태그만 있는 짧은 글이 만들어지고, 폰에서 나중에 사진과 본문을 덧붙인다. 제휴 핀(확대 계획)은 같은 지도에 "제휴" 표시로 따로 뜨는 다른 종류다.

7. 결정

  1. 정함 메인 홈: 내 차(B) + 바로 쓰는 차 기능 버튼
  2. 정함 그룹 라이딩: 늘 떠 있는 메뉴에서 빼고, 진행 중일 때만 떠 있는 배너. 시작은 홈 버튼
  3. 정함 이웃: 서로 수락하는 관계. 프로필 아이디로 추가. 그룹 라이딩은 이웃끼리
  4. 정함 지도: 네이버 지도 SDK (차·폰 공통)
  5. 정함 메뉴: 아래쪽 가로 플로팅, 내용 영역을 차지하지 않음. 스크롤하거나 5초 지나면 손잡이로 접힘
  6. 정함 내 경로 위 제보: 화면 위에서 내려오는 꽉 찬 배너 "현재 경로 위에 사고 제보가 있어요", 누르면 위치
  7. 정함 화면 문구는 UX 라이팅 기준의 용어집을 따름
  8. 정함 홈에서 실시간 제보: 사고, 공사, 정체, 단속카메라, 재난
  9. 정함 그룹 라이딩 화면: 무전기 앱처럼 멤버 프로필과 큰 말하기 버튼, 말하는 사람 강조
  10. 남음: 장소 핀을 "위치 붙은 글"로 합치는 것이 맞는지
  11. 남음: 그룹 라이딩 지도 표시(주유소·충전소, 핀) 기본값 꺼짐 / 켜짐
  12. 남음: 홈의 바로 쓰는 버튼 목록 확정
