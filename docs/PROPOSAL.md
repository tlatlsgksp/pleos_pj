# Moli: 내 차로 함께 달리는 드라이버 커뮤니티

접수양식 02장 "앱 프로젝트 소개"와 참고자료(심사 자료)에 넣을 초안이다. 심사위원이 읽을 문장만 담는다. 앱 이름 Moli(몰리)는 Mobility Life의 줄임말이다.

- 작성일: 2026-11-15 (v2.1 초안, 기획 담당이 다듬는다)
- 블라인드 심사: 성명, 연락처, 소속, 회사명, 기존 서비스명을 쓰지 않는다.
- `[ ]`로 표시한 곳은 팀이 정하거나 채워야 하는 곳이다. 맨 끝 "제출 전 확인"에 모았다.
- **실측**은 Pleos Connect 에뮬레이터에서 직접 확인했다는 뜻이다. **구현**은 1차 제출 앱에 들어 있다는 뜻이다.

## 1. 앱 한 줄 소개

> **내 차로 함께 달리는 드라이버 커뮤니티.** 차에서 꾸민 내 차가 스마트폰 커뮤니티의 프로필이 된다. 차가 직접 잰 연비로 순위를 겨루고, 무드등이 연비 운전을 코치하고, 친구와 위치를 나누며 워키토키로 이야기한다. 차로 가 보고 좋았던 장소를 지도에 핀해 서로 추천하고, 주유·충전 가격은 차가 감지한 실제 결제 정보로 알려 준다. 연료차와 전기차를 모두 지원한다.

## 2. 기획 배경

### 2.1 운전자들이 서로 궁금해하는 것

| 궁금한 순간 | 지금 하는 일 | 아쉬운 점 |
|---|---|---|
| 내 연비가 좋은 편인지 궁금할 때 | 오너 카페에 계기판 사진을 올리고 비교한다 | 찍는 순간만 보여 주고, 조건이 제각각이라 믿기 어렵다 |
| 어디가 싼지 궁금할 때 | 가격 앱을 따로 열거나 카페 글을 뒤진다 | 운전 중에는 볼 수 없고, 내가 가진 카드 브랜드와 맞지 않는다 |
| 친구들과 같이 달릴 때 | 단체 통화를 켜거나 메신저로 "어디야?"를 묻는다 | 운전 중 폰 조작이 위험하고, 누가 어디쯤인지 한눈에 안 보인다 |
| 차로 갈 만한 곳을 찾을 때 | 블로그·지도 앱 리뷰를 뒤진다 | 차로 가는 사람 기준(주차, 충전기, 드라이브 길)의 정보가 없다 |
| 내 차를 자랑하고 싶을 때 | 사진을 찍어 SNS에 올린다 | 차와 연결된 프로필이 없어, 어떤 차를 어떻게 타는 사람인지 드러나지 않는다 |

자동차 커뮤니티는 이미 크다. 하지만 모든 정보가 **사람이 찍어서 올린 사진과 글**이라 연비 비교는 믿기 어렵고, 차 안에서는 커뮤니티와 끊긴다. `[근거: 오너 커뮤니티 규모, 연비 인증 게시판 활동량 공개 자료]`

### 2.2 왜 차와 폰이 함께여야 하는가

- **차는 사실을 안다.** 연비·전비, 주유·충전량, 주행거리를 차가 직접 잰다. 커뮤니티에 올라가는 숫자가 사진이 아니라 차량 신호가 된다. 에뮬레이터에서 총 주행거리와 배터리 값을 바꾸면 앱이 바로 받는다(실측).
- **차는 운전 중에도 말을 걸 수 있다.** 화면을 보지 않아도 무드등 색과 음성으로 알려 줄 수 있다. 앱이 실내 무드등 색을 바꾸는 것을 확인했다(실측).
- **폰은 차 밖의 시간을 맡는다.** 글 쓰기, 순위 보기, 친구 맺기, 내 차 자랑은 차에서 내린 뒤 폰에서 한다.

Moli는 **차에서 생긴 사실을 폰 커뮤니티로 옮기고**, 커뮤니티에서 모인 정보를 **다시 차의 운전으로 돌려준다.**

### 3.2 차와 폰의 역할, 주행 중과 정차 중

앱 카테고리는 **Mobility Services**다. 운전 중에는 화면을 보지 않고 쓰는 기능만 연다.

| 상황 | 차에서 쓸 수 있는 기능 | 방식 |
|---|---|---|
| 주행 중 | 연비 코치 무드등, 워키토키, 충전소·주유소 경유 제안 | 무드등 색과 음성. 화면은 카드 한 장과 버튼 두 개. 글 읽기·쓰기 없음 |
| 정차 중 | 내 차 꾸미기, 장소 핀하기, 순위, 친구 위치 목록, 주유·충전 기록 확인 | 전체 화면 |
| 차에서 내린 뒤 | — | 폰 앱에서 피드, 글 쓰기, 댓글, 친구 맺기 |

차와 폰은 **QR 한 번으로 연결**한다. 차 화면의 QR을 폰으로 찍고 로그인하면 계정이 연결되고, 이후 기록과 순위, 친구 목록이 서버를 거쳐 양쪽에 맞춰진다.

### 3.3 차별점

| | 오너 커뮤니티·카페 | 모바일 차계부 | Moli |
|---|---|---|---|
| 연비 비교 | 계기판 사진 | 직접 입력한 값 | 차가 잰 값, 공회전 제외 |
| 가격 정보 | 사람이 쓴 글 | 없음 | 차가 감지한 실제 결제 정보 |
| 운전 중 | 쓸 수 없음 | 쓸 수 없음 | 무드등 코치, 워키토키, 경유지 |
| 같이 달리기 | 단체 통화·메신저 | 없음 | 위치 공유와 워키토키, 친구에게 바로 경로 |
| 장소 추천 | 일반 리뷰 | 없음 | 차로 가는 사람 기준(주차, 충전기, 드라이브 길), 바로 경로로 |
| 프로필 | 닉네임과 사진 | 없음 | 꾸민 내 차와 연비 등급 |

## 4. 주요 사용 시나리오

### 시나리오 A. 주말 동호회 드라이브: "누가 어디쯤인지, 말로 묻는다"

- **누가**: 같은 차종 동호회 5명. 지난번엔 단체 통화가 자꾸 끊기고 한 명이 길을 잃었다.
- **흐름**
  1. 모임장이 폰에서 그룹 드라이브를 만들고 목적지를 정한다. 멤버의 차 화면에 "그룹 드라이브에 참여할까요?"가 뜬다.
  2. 참여하면 목적지가 내비에 들어가고, 차 화면에 멤버 목록이 "민수 1.2 km 앞, 지은 0.8 km 뒤"처럼 보인다.
  3. "다음 휴게소에서 쉬자"는 핸들 버튼을 누르고 말한다. 멤버 차에서 음악이 잠깐 줄고 목소리가 나온다.
  4. 뒤처진 멤버는 [민수에게 가기] 한 번으로 앞 차의 위치를 경유지로 넣는다.
- **사용 API**: NaviHelper(현재 위치·진행 방향, 목적지·경유지 설정), 차량 마이크, 오디오 포커스

### 시나리오 B. 연비 리그: "무드등이 알려 주고, 순위가 동기가 된다"

- **누가**: 30대 직장인, 전기차 운전자. 같은 차종 운전자 중 내 전비가 어느 정도인지 궁금하다.
- **흐름**
  1. 출근길에 급하게 출발하자 무드등이 주황으로 바뀐다. 천천히 밟자 원래 색으로 돌아온다.
  2. 도착하면 차 화면에 "오늘 6.2 km/kWh, 같은 차종 상위 12%" 카드가 뜬다.
  3. 점심시간에 폰 알림을 눌러 카드를 피드에 올린다. 친구가 "나도 이번 주 6 넘겼다"고 댓글을 단다.
  4. 주말에 주간 순위가 발표되고, 프로필의 내 차 옆에 이번 주 등급이 붙는다.
- **사용 API**: Vehicle(무드등 제어, 총 주행거리, 배터리 에너지), 차속

### 시나리오 C. 주유·충전: "차가 결제 정보를 알려 주고, 모두가 덕을 본다"

- **누가**: 연료차 운전자. 주유 카드가 있는 브랜드에서만 넣는다.
- **흐름**
  1. 연료가 부족해지자 카드가 뜬다. "가는 길 오른쪽, 선호 브랜드, 커뮤니티 제보 기준 리터당 1,612원. 들르면 3분 더." [들르기] [나중에]
  2. [들르기]를 누르면 주유소가 내비 경유지로 들어간다.
  3. 주유를 마치면 차가 주유량을 감지해 기록을 만든다. 금액을 확인하면 그 주유소의 오늘 가격이 커뮤니티에 제보된다.
  4. 같은 길을 가는 다른 운전자는 방금 제보된 가격으로 주유소를 고른다.
- **사용 API**: Vehicle(연료량, 총 주행거리), NaviHelper(경유지 추가, 현재 위치·진행 방향), 오피넷 API

### 시나리오 D. 내 차 꾸미기: "커뮤니티에서 나는 내 차로 보인다"

- **누가**: 차를 새로 산 20대 운전자.
- **흐름**
  1. 정차 중 [내 차]에서 3D 차량에 무광 그레이 랩핑을 입히고 무드등을 하늘색으로 고른다. 실내등이 바로 하늘색으로 바뀐다.
  2. 폰 앱의 프로필 사진이 방금 꾸민 차로 바뀐다.
  3. 같은 차종 운전자들의 꾸미기가 피드에 모이고, 마음에 드는 조합을 내 차에 그대로 적용한다.
- **사용 API**: Vehicle(무드등 색 제어)

### 시나리오 E. 차로 가 본 곳: "주차까지 편했던 바닷가 카페"

- **누가**: 주말마다 드라이브를 가는 전기차 운전자.
- **흐름**
  1. 바닷가 카페에 주차하고 [지금 여기 핀하기]를 누른다. 태그 "카페", "주차 쉬움", "충전기 있음"을 고르고 한 줄 추천을 남긴다.
  2. 같은 차종 오너가 다음 주말 그 근처를 지나며 차 화면의 [근처 추천]에서 이 카페를 본다.
  3. [경유지로]를 누르면 가는 길에 들르도록 내비에 들어간다.
  4. 다녀온 뒤 폰에서 사진을 덧붙이고 응원을 남긴다.
- **사용 API**: NaviHelper(현재 위치·진행 방향, 목적지·경유지 설정), Vehicle(기어)

## 5. 개발 계획

### 5.1 구현 구조

```
차량 (Pleos Connect, AAOS)
  Moli 차량 앱 (Kotlin, Jetpack Compose, MVI)        ← 1차 구현
    ├─ Vehicle SDK      총 주행거리·배터리·연료·충전구·무드등 제어·VIN
    ├─ NaviHelper SDK   현재 위치·진행 방향, 목적지·경유지 설정
    ├─ AAOS             차속, 마이크, 오디오 포커스
    └─ Room DB          주유·충전 기록. 오프라인에서도 동작
          │ HTTPS · WebSocket (계정을 연결하고 동의한 경우만)
백엔드 (NestJS, PostgreSQL, Redis)                  ← 유가 API 구현, 나머지 설계
    계정·차 연결(QR), 피드·댓글, 연비 순위 집계, 가격 제보, 장소 핀,
    그룹 위치 중계, 워키토키 음성 중계, 유가·충전소 캐시
          │
스마트폰 앱                                         ← 1차 설계
    피드, 순위, 지도(친구·장소 핀·가격), 그룹·워키토키, 내 차
```

- **연비 순위의 신뢰도**: 순위에 쓰는 값은 차량 앱이 차량 신호로 계산한 주행 효율만 받는다. 사용자가 고칠 수 없고, 같은 차종끼리 비교한다.
- **위치 공유**: 그룹 드라이브에 참여한 동안에만 위치를 보낸다. 끝나면 서버에 남기지 않는다.
- **워키토키**: 누르는 동안 녹음한 짧은 음성을 서버가 그룹에 바로 전달한다. 실시간 통화보다 연결이 단순해 차량 오디오와 충돌이 적다.
- **주행 안전**: 주행 중에는 `CarUxRestrictions`를 따라 무드등, 음성, 카드 한 장만 쓴다. 글 읽기와 쓰기는 폰과 정차 중에만 연다.
- **차종 호환**: 모델명으로 분기하지 않고 지원 여부 확인 함수(`checkXxxCapabilities`)로 판단해, 지원하지 않는 기능은 숨긴다.
- **커뮤니티 운영**: 글·핀·댓글에 신고 버튼을 두고, 신고가 쌓이면 자동으로 숨긴 뒤 운영자가 확인한다. 사용자는 다른 사용자를 차단할 수 있다. 핀은 정차 중 실제 위치에서만 만들 수 있어 허위 장소 등록을 줄인다.
- **개인정보**: 차량 데이터와 기록은 기기 안에 저장한다. 서버로는 계정을 연결하고 동의한 사용자의 순위용 요약값(차종, 주간 평균 효율), 가격 제보, 그룹 드라이브 중 위치만 보낸다.

### 5.2 UI 설계 원칙

Pleos Connect 가이드의 안전·크기 기준을 지키고, 시각적 정체성은 Moli만의 것으로 만든다.

- 주행 화면 옆 2/3 창과 앱 두 개를 띄운 1/3 창에 모두 맞춘다. 2/3 창에서는 목록과 상세를 나란히 보여 준다.
- 본문은 최소 26 크기, 터치 영역은 장갑 낀 손가락 기준으로 잡는다. 한글 글꼴은 SUIT를 쓴다.
- 바탕은 순백 대신 차가운 회색, 강조색은 하나만 쓰고 "지금 내 차"를 뜻하는 곳에만 칠한다. Light·Dark 테마를 모두 지원한다.
- 주행 중에는 화면보다 무드등과 음성으로 알린다. 카드는 정보 한 줄과 버튼 두 개로 제한한다.

### 6.2 사용자 확보와 지속 이용

- **확보**: 친구 초대가 곧 그룹 드라이브다. 한 명이 그룹을 만들면 멤버 모두가 앱을 깔게 된다. 연비 인증 카드는 폰 밖 SNS로도 공유된다.
- **예상 MAU**: Pleos Connect 탑재 차량 수 `[ ]` × 설치율 `[ ]` × 월 1회 이상 실행률 `[ ]`
- **지속 이용이 높은 이유**
  - 주간 순위가 매주 다시 볼 이유를 만든다.
  - 운전할 때마다 무드등 코치와 인증 카드가 자동으로 생겨, 따로 할 일 없이 참여가 쌓인다.
  - 친구와 동호회 그룹은 한번 만들면 쉽게 떠나지 않는다.

### 6.3 확대 계획

1. **업주 제휴 핀**: 가게·카페·충전소 업주가 Moli 지도에 제휴 핀을 띄운다. 운전자가 직접 핀한 장소와 섞지 않고 "제휴"로 분명히 표시하며, 운전자 추천 순위에는 넣지 않는다. 주행 중에는 보여 주지 않고, 정차 중이나 폰 지도에서 가는 길·태그(주차 쉬움, 충전기 있음 등)가 맞을 때만 보여 준다. 업주는 실제로 들른 Moli 차량 수(가명 집계)를 리포트로 받는다.
2. **브랜드 제휴**: 주유·충전 브랜드가 연비 리그와 그룹 드라이브에 맞춘 혜택을 커뮤니티에 제공한다.
3. **꾸미기 확장**: 랩핑·무드등 조합을 공유하고, 차종별 한정 꾸미기를 이벤트로 연다.
4. **동호회 이벤트**: 같은 차종 동호회의 그룹 드라이브와 연비 대회를 앱 안에서 연다.
5. **안전 운전 연계**: 연비 코치로 쌓인 부드러운 운전 기록을 사용자 동의 아래 안전 운전 혜택과 연결한다.
6. **Pleos API 개방과 함께 넓히기**: 핸들 사용자 지정 키(워키토키), 시동 이벤트, 주행 화면 차량 테마 등 지금 열려 있지 않은 기능을 우회 방법과 안전 장치까지 붙여 제안서로 정리했다.
