## 1. 앱 한 줄 소개

> **내 차로 함께 달리는 드라이버 커뮤니티.** 차에서 꾸민 내 차가 스마트폰 커뮤니티의 프로필이 된다. 차가 직접 잰 연비로 순위를 겨루고, 무드등이 연비 운전을 코치한다. 이웃과 그룹 라이딩을 하며 위치를 나누고 워키토키로 이야기한다. 차로 가 보고 좋았던 장소를 지도에 핀으로 남겨 서로 추천하고, 사고·공사·정체 같은 길 소식을 버튼 한 번으로 제보한다. 연료차와 전기차를 모두 지원한다.

## 2. 기획 배경

### 2.1 운전자들이 서로 궁금해하는 것

| 궁금한 순간 | 지금 하는 일 | 아쉬운 점 |
|---|---|---|
| 내 연비가 좋은 편인지 궁금할 때 | 오너 카페에 계기판 사진을 올리고 비교한다 | 찍는 순간만 보여 주고, 조건이 제각각이라 믿기 어렵다 |
| 어디가 싼지 궁금할 때 | 가격 앱을 따로 열거나 카페 글을 뒤진다 | 운전 중에는 볼 수 없고, 내가 가진 카드 브랜드와 맞지 않는다 |
| 앞길에 사고나 단속이 있는지 궁금할 때 | 내비 안내를 기다리거나 라디오를 듣는다 | 같은 길을 먼저 지나간 운전자가 본 것을 바로 알 수 없다 |
| 친구들과 같이 달릴 때 | 단체 통화를 켜거나 메신저로 "어디야?"를 묻는다 | 운전 중 폰 조작이 위험하고, 누가 어디쯤인지 한눈에 안 보인다 |
| 차로 갈 만한 곳을 찾을 때 | 블로그·지도 앱 리뷰를 뒤진다 | 차로 가는 사람 기준(주차, 충전기, 드라이브 길)의 정보가 없다 |
| 내 차를 자랑하고 싶을 때 | 사진을 찍어 SNS에 올린다 | 차와 연결된 프로필이 없어, 어떤 차를 어떻게 타는 사람인지 드러나지 않는다 |

자동차 커뮤니티는 이미 크다. 하지만 모든 정보가 **사람이 찍어서 올린 사진과 글**이라 연비 비교는 믿기 어렵고, 차 안에서는 커뮤니티와 끊긴다. `[근거: 오너 커뮤니티 규모, 연비 인증 게시판 활동량 공개 자료]`

### 2.2 왜 차와 폰이 함께여야 하는가

- **차는 사실을 안다.** 연비·전비, 주유·충전량, 주행거리를 차가 직접 잰다. 커뮤니티에 올라가는 숫자가 사진이 아니라 차량 신호가 된다. 에뮬레이터에서 총 주행거리와 배터리 값을 바꾸면 앱이 바로 받는다(실측).
- **차는 운전 중에도 말을 걸 수 있다.** 화면을 보지 않아도 무드등 색과 음성으로 알려 줄 수 있다. 앱이 실내 무드등 색을 바꾸는 것을 확인했다(실측).
- **커뮤니티는 차와 폰 모두에 있다.** 차에서는 운전하면서 참여할 수 있는 것(연비 랭킹, 그룹 라이딩, 핀, 제보)만 두고, 글을 읽고 쓰는 커뮤니티는 폰에 둔다.

Moli는 **차에서 생긴 사실을 폰 커뮤니티로 옮기고**, 커뮤니티에서 모인 정보를 **다시 차의 운전으로 돌려준다.**

**E. 핀: 차 타는 사람들의 장소 추천**

핀은 위치를 붙인 커뮤니티 글이다. 따로 장소 데이터를 만들지 않고, 글에 위치가 있으면 지도에 핀으로 뜬다.

| 기능 | 하는 일 | 차량 특화 요소 |
|---|---|---|
| 핀 남기기 | 정차 중 버튼 한 번으로 지금 있는 곳에 핀을 남기고 이름과 한 줄 추천을 쓴다. 종류를 고르는 대신 태그를 여러 개 단다. "주차 쉬움", "충전기 있음", "차박·큰 차 편함", "드라이브 코스"처럼 차로 가는 사람에게 필요한 태그와 "맛집", "저렴한 주유소" 같은 태그를 함께 고르거나 직접 만든다. 기본은 전체 공개이고 이웃만으로 바꿀 수 있다 | NaviHelper 현재 위치(실측), 기어 P일 때만 입력 |
| 지도의 핀 | 다른 운전자의 핀을 가까운 곳, 가는 길 기준으로 보여 주고 태그로 거른다. 같은 차종 오너의 핀을 먼저 보여 준다 | NaviHelper 현재 위치·진행 방향 |
| 길 안내·경유지 추가 | 마음에 드는 핀을 목적지나 경유지로 바로 넣는다 | NaviHelper 목적지·경유지 설정, 확인창 없이 반영(실측) |
| 폰에서 덧붙이기 | 차에서 남긴 핀을 폰에서 열어 사진과 글을 덧붙인다. 폰 지도에서 핀을 저장하고 [차로 보내기]로 차의 목적지에 넣는다 | — |

### 3.2 차와 폰의 역할, 주행 중과 정차 중

앱 카테고리는 **Mobility Services**다. 차량 앱은 메뉴 네 개(홈, 랭킹, 지도, 나)를 화면 왼쪽 아래에 세로로 띄운다. 메뉴는 화면 영역을 차지하지 않고, 스크롤하거나 5초가 지나면 가장자리 손잡이로 접힌다. 운전 중에는 한 번 눌러 끝나는 기능만 연다.

| 상황 | 차에서 쓸 수 있는 기능 | 방식 |
|---|---|---|
| 주행 중 | 연비 코치 무드등, 빠른 실행(핀 남기기 제외), 제보, 그룹 라이딩 참여와 워키토키, 경로 위 제보 알림 | 무드등 색과 음성, 큰 버튼 한 번. 글 읽기·쓰기 없음 |
| 정차 중 | 핀 남기기, 핀 글 전체 보기, 이웃 추가, 닉네임 변경, 꾸미기, 주행 리포트, 주유·충전 기록, 차량 정보 | 전체 화면 |
| 차에서 내린 뒤 | — | 폰 앱에서 커뮤니티 글, 댓글, 사진, 이웃 관리 |

차와 폰은 **QR 한 번으로 연결**한다. 차 화면의 QR을 폰으로 찍고 로그인하면 계정이 연결되고, 이후 기록과 순위, 이웃 목록이 서버를 거쳐 양쪽에 맞춰진다.

### 3.3 차별점

| | 오너 커뮤니티·카페 | 모바일 차계부 | Moli |
|---|---|---|---|
| 연비 비교 | 계기판 사진 | 직접 입력한 값 | 차가 잰 값, 공회전 제외 |
| 가격 정보 | 사람이 쓴 글 | 없음 | 차가 감지한 실제 결제 정보 |
| 운전 중 | 쓸 수 없음 | 쓸 수 없음 | 무드등 코치, 워키토키, 버튼 두 번 제보, 경유지 |
| 같이 달리기 | 단체 통화·메신저 | 없음 | 그룹 라이딩: 위치 공유, 워키토키, 목적지 자동 설정 |
| 길 소식 | 내비 안내, 라디오 | 없음 | 같은 길의 운전자가 올린 제보, 내 경로 위면 바로 알림 |
| 장소 추천 | 일반 리뷰 | 없음 | 차로 가는 사람 기준(주차, 충전기, 드라이브 길), 바로 경로로 |
| 프로필 | 닉네임과 사진 | 없음 | 꾸민 내 차와 이번 주 순위 |

## 4. 주요 사용 시나리오

### 시나리오 A. 주말 동호회 그룹 라이딩: "서로 보이고, 버튼 하나로 말한다"

- **누가**: 같은 차종 동호회 이웃 5명. 지난번엔 단체 통화가 자꾸 끊기고 한 명이 길을 잃었다.
- **흐름**
  1. 모임장이 홈의 [그룹 라이딩]에서 이웃 네 명을 고르고 목적지를 정한다. 멤버의 차 화면 위로 "민수의 그룹 라이딩에 참여할까요?"가 내려온다.
  2. [참여]를 누르면 목적지가 내비에 들어가고, 지도에 멤버들의 꾸민 차가 보이고, 아래에 멤버 프로필이 한 줄로 뜬다.
  3. "다음 휴게소에서 쉬자"는 핸들 버튼을 누르고 말한다. 멤버 차에서 음악이 잠깐 멈추고 목소리가 나오며, 말하는 사람의 프로필이 밝아진다.
  4. 휴게소에서 뒤처진 멤버는 민수의 프로필을 눌러 그 위치를 경유지로 넣는다.
- **사용 API**: NaviHelper(현재 위치·진행 방향, 목적지·경유지 설정), 차량 마이크, 오디오 포커스

### 시나리오 B. 연비 랭킹: "무드등이 알려 주고, 순위가 동기가 된다"

- **누가**: 30대 직장인, 전기차 운전자. 같은 차종 운전자 중 내 전비가 어느 정도인지 궁금하다.
- **흐름**
  1. 출근길에 급하게 출발하자 무드등이 주황으로 바뀐다. 천천히 밟자 원래 색으로 돌아온다.
  2. 도착하면 이번 주행의 주행 카드(6.2 km/kWh, 같은 차종 상위 12%)가 만들어진다. 랭킹의 주행 리포트에서 급가속 1회, 급감속 2회를 확인한다.
  3. 점심시간에 폰 알림을 눌러 카드를 커뮤니티에 올린다. 이웃이 "나도 이번 주 6 넘겼다"고 댓글을 단다.
  4. 주말에 주간 순위가 나오고, 프로필의 내 차 옆에 이번 주 순위가 붙는다.
- **사용 API**: Vehicle(무드등 제어, 총 주행거리, 배터리 에너지), 차속

### 시나리오 C. 주유·충전: "차가 결제 정보를 알려 주고, 모두가 덕을 본다"

- **누가**: 연료차 운전자. 주유 카드가 있는 브랜드에서만 넣는다.
- **흐름**
  1. 연료가 부족해지자 카드가 뜬다. 가는 길 오른쪽의 내 카드 브랜드 주유소, 커뮤니티 기준 리터당 1,612원. [들르기] [나중에]
  2. [들르기]를 누르면 주유소가 내비 경유지로 들어간다.
  3. 주유를 마치면 차가 주유량을 감지해 기록을 만든다. 금액을 확인하면 그 주유소의 오늘 단가가 커뮤니티에 공유된다.
  4. 같은 길을 가는 다른 운전자는 방금 공유된 가격으로 주유소를 고른다.
- **사용 API**: Vehicle(연료량, 총 주행거리), NaviHelper(경유지 추가, 현재 위치·진행 방향), 오피넷 API

### 시나리오 D. 내 차 꾸미기: "커뮤니티에서 나는 내 차로 보인다"

- **누가**: 차를 새로 산 20대 운전자.
- **흐름**
  1. 정차 중 [나 › 꾸미기]에서 3D 차량에 무광 그레이 랩핑을 입히고 무드등을 하늘색으로 고른다. 실내등이 바로 하늘색으로 바뀐다.
  2. 폰 앱의 프로필 사진이 방금 꾸민 차로 바뀐다.
  3. 차를 켤 때마다 홈 위쪽에 꾸민 차가 서 있다. 같은 차종 운전자들의 꾸미기가 커뮤니티에 모이고, 마음에 드는 조합을 내 차에 그대로 적용한다.
- **사용 API**: Vehicle(무드등 색 제어)

### 시나리오 E. 차로 가 본 곳: "주차까지 편했던 바닷가 카페"

- **누가**: 주말마다 드라이브를 가는 전기차 운전자.
- **흐름**
  1. 바닷가 카페에 주차하고 홈의 [핀 남기기]를 누른다. 태그 "카페", "주차 쉬움", "충전기 있음"을 고르고 한 줄 추천을 남긴다.
  2. 같은 차종 오너가 다음 주말 그 근처를 지나며 차의 지도에서 "주차 쉬움" 태그로 이 카페를 찾는다.
  3. [경유지 추가]를 누르면 가는 길에 들르도록 내비에 들어간다.
  4. 처음 핀을 남긴 운전자는 집에 와서 폰으로 그 핀에 사진과 글을 덧붙인다.
- **사용 API**: NaviHelper(현재 위치·진행 방향, 목적지·경유지 설정), Vehicle(기어)

### 시나리오 F. 길 소식: "먼저 지나간 사람이 알려 준다"

- **누가**: 퇴근길 고속도로를 타는 운전자.
- **흐름**
  1. 앞서 가던 운전자가 사고 현장을 지나며 홈의 [제보] → [사고]를 누른다. 버튼 두 번이라 운전 중에도 된다.
  2. 같은 길로 안내받던 다른 운전자의 화면 위로 "현재 경로 위에 사고 제보가 있어요"가 내려오고 짧은 음성이 나온다.
  3. 배너를 누르면 사고 지점이 지도에 보인다. 우회할지 정한다.
  4. 그 지점을 지나는 운전자들이 [아직 있어요] [없어졌어요]로 확인해, 정리된 사고는 금방 지도에서 내려간다.
- **사용 API**: NaviHelper(현재 위치·진행 방향, 경로 정보)

## 5. 개발 계획

### 5.1 구현 구조

```
차량 (Pleos Connect, AAOS)
  Moli 차량 앱 (Kotlin, Jetpack Compose, MVI)        ← 1차 구현
    ├─ Vehicle SDK      총 주행거리·배터리·연료·충전구·무드등 제어·VIN
    ├─ NaviHelper SDK   현재 위치·진행 방향, 목적지·경유지 설정
    ├─ AAOS             차속, 마이크, 오디오 포커스
    └─ Room DB          주유·충전 기록. 오프라인에서도 동작
          │ HTTPS · WebSocket (계정을 연결하고 동의한 경우만)
백엔드 (NestJS, PostgreSQL, Redis)                  ← 스캐폴드, 설계
    계정·차 연결(QR), 이웃, 커뮤니티 글·댓글(위치 붙은 글 = 핀), 연비 랭킹 집계, 제보, 가격 공유,
    그룹 위치 중계, 워키토키 음성 중계, 유가·충전소 캐시
          │
스마트폰 앱                                         ← 1차 설계
    커뮤니티, 지도(핀·제보·가격·멤버), 랭킹, 나(이웃·그룹 라이딩)
```

- **연비 순위의 신뢰도**: 순위에 쓰는 값은 차량 앱이 차량 신호로 계산한 주행 효율만 받는다. 사용자가 고칠 수 없고, 같은 차종끼리 비교한다.
- **위치 공유**: 그룹 라이딩에 참여한 동안에만 위치를 보낸다. 끝나면 서버에 남기지 않는다.
- **워키토키**: 누르는 동안 녹음한 짧은 음성을 서버가 그룹에 바로 전달한다. 실시간 통화보다 연결이 단순해 차량 오디오와 충돌이 적다.
- **주행 안전**: 주행 중에는 `CarUxRestrictions`를 따라 무드등, 음성, 한 번 눌러 끝나는 버튼만 쓴다. 글 읽기와 쓰기, 키보드 입력은 폰과 정차 중에만 연다.
- **차종 호환**: 모델명으로 분기하지 않고 지원 여부 확인 함수(`checkXxxCapabilities`)로 판단해, 지원하지 않는 기능은 숨긴다.
- **커뮤니티 운영**: 글·핀·댓글·제보에 신고 버튼을 두고, 신고가 쌓이면 자동으로 숨긴 뒤 운영자가 확인한다. 사용자는 다른 사용자를 차단할 수 있다. 핀과 제보는 차가 준 실제 위치로만 만들 수 있어 허위 등록을 줄인다. 제보는 종류마다 보이는 시간이 정해져 있고, 지나간 운전자의 확인으로 일찍 내려간다.
- **개인정보**: 차량 데이터와 기록은 기기 안에 저장한다. 서버로는 계정을 연결하고 동의한 사용자의 순위용 요약값(차종, 주간 평균 효율), 가격 공유, 핀과 제보의 위치, 그룹 라이딩 중 위치만 보낸다.

### 5.2 UI 설계 원칙

Pleos Connect 가이드의 안전·크기 기준을 지키고, 시각적 정체성은 Moli만의 것으로 만든다.

- 주행 화면 옆 2/3 창과 앱 두 개를 띄운 1/3 창에 모두 맞춘다.
- 화면 위쪽 탭과 제목 바를 쓰지 않는다. 메뉴는 왼쪽 아래에 떠 있다가 접혀서, 지도와 3D 차가 화면 전체를 쓴다.
- 알림은 위에서 내려오는 꽉 찬 배너 하나로 통일한다(경로 위 제보, 그룹 라이딩 초대, 이웃 요청).
- 화면 문구는 팀의 UX 라이팅 기준(해요체, 주행 중 문구 한 줄, 누르면 일어나는 일로 버튼 이름 짓기)을 따른다.
- 본문은 최소 26 크기, 터치 영역은 장갑 낀 손가락 기준으로 잡는다. 한글 글꼴은 SUIT를 쓴다.
- 바탕은 순백 대신 차가운 회색, 강조색은 하나만 쓰고 "지금 내 차"를 뜻하는 곳에만 칠한다. Light·Dark 테마를 모두 지원한다.
- 주행 중에는 화면보다 무드등과 음성으로 알린다. 카드는 정보 한 줄과 버튼 두 개로 제한한다.

## 6. 기대효과와 발전 가능성

### 6.1 타깃 고객

| 구분 | 고객 | 핵심 가치 |
|---|---|---|
| 1차 | Pleos Connect 탑재 차량의 20~40대 운전자, 같은 차종 오너 커뮤니티 활동자 | 믿을 수 있는 연비 비교, 내 차로 드러나는 프로필 |
| 2차 | 이웃·가족·동호회와 함께 달리는 운전자 | 그룹 라이딩: 위치 공유와 워키토키 |
| 3차 | 출퇴근길이 정해진 운전자 | 같은 길 운전자의 실시간 제보 |
| 4차 | 주유·충전비를 아끼고 싶은 운전자 | 실제 결제 기반 가격 정보, 내 카드 브랜드 경유 |

### 6.2 사용자 확보와 지속 이용

- **확보**: 이웃 초대가 곧 그룹 라이딩이다. 한 명이 그룹 라이딩을 열면 멤버 모두가 앱을 쓰게 된다. 차가 없는 동승자와 다른 차의 이웃도 폰으로 참여한다. 주행 카드는 폰 밖 SNS로도 공유된다.
- **예상 MAU**: Pleos Connect 탑재 차량 수 `[ ]` × 설치율 `[ ]` × 월 1회 이상 실행률 `[ ]`
- **지속 이용이 높은 이유**
  - 주간 순위가 매주 다시 볼 이유를 만든다.
  - 운전할 때마다 무드등 코치와 주행 카드가 자동으로 생겨, 따로 할 일 없이 참여가 쌓인다.
  - 출퇴근길 제보는 매일 같은 길을 달리는 운전자에게 매일 쓸모가 있다.
  - 이웃과 동호회 관계는 한번 생기면 쉽게 떠나지 않는다.

### 6.3 확대 계획

1. **업주 제휴 핀**: 가게·카페·충전소 업주가 Moli 지도에 제휴 핀을 띄운다. 운전자가 직접 핀한 장소와 섞지 않고 "제휴"로 분명히 표시하며, 운전자 추천 순위에는 넣지 않는다. 주행 중에는 보여 주지 않고, 정차 중이나 폰 지도에서 가는 길·태그(주차 쉬움, 충전기 있음 등)가 맞을 때만 보여 준다. 업주는 실제로 들른 Moli 차량 수(가명 집계)를 리포트로 받는다.
2. **브랜드 제휴**: 주유·충전 브랜드가 연비 랭킹과 그룹 라이딩에 맞춘 혜택을 커뮤니티에 제공한다.
3. **꾸미기 확장**: 랩핑·무드등 조합을 공유하고, 차종별 한정 꾸미기를 이벤트로 연다.
4. **동호회 이벤트**: 같은 차종 동호회의 그룹 라이딩과 연비 대회를 앱 안에서 연다.
5. **안전 운전 연계**: 연비 코치로 쌓인 부드러운 운전 기록을 사용자 동의 아래 안전 운전 혜택과 연결한다.
6. **Pleos API 개방과 함께 넓히기**: 핸들 사용자 지정 키(워키토키), 시동 이벤트, 주행 화면 차량 테마 등 지금 열려 있지 않은 기능을 우회 방법과 안전 장치까지 붙여 제안서로 정리했다.
