### D. 차로 가 본 곳 핀 (새로 추가)

차를 탄다는 공통점 속에서, 차로 가 보고 좋았던 장소를 핀하고 나누는 기능.

| ID | 기능 | 차 | 폰 | 상태 | 설명 |
|---|---|---|---|---|---|
| D1 | 지금 여기 핀하기 | ● | ● | 설계 | 정차 중 지금 위치를 핀. 이름, 태그 여러 개, 한 줄 추천 |
| D2 | 근처·가는 길 추천 | ● | ● | 설계 | 가까운 순 / 경로 주변. 같은 차종 오너 추천 먼저 |
| D3 | 바로 가기 | ● | | 설계 | 목적지 또는 경유지로 넣기 |
| D4 | 저장·응원·후기 | | ● | 설계 | 폰에서 저장, 응원, 사진 후기 덧붙이기 |

태그는 고정된 종류가 아니라 여러 개를 자유롭게 단다. 추천 태그는 차로 가는 사람 기준(주차 쉬움, 충전기 있음, 차박·큰 차 편함, 드라이브 코스)과 일반 장소(맛집, 카페, 저렴한 주유소)를 함께 보여 준다.

## 2. 주행 중 규칙

| 상황 | 허용 | 금지 |
|---|---|---|
| 주행 중 | 무드등(B1), 음성(C5), 카드 한 장 + 버튼 두 개(E4 경유 제안, C2 참여) | 글 읽기·쓰기, 핀 입력(D1), 목록 스크롤 |
| 정차 중 (기어 P) | 차 기능 전부 | — |
| 폰 | 커뮤니티 기능 전부 | 운전자의 폰 조작은 앱이 막지 않음(안내만) |

## 3. 데이터 출처 원칙

- 커뮤니티에 올라가는 숫자는 차가 만든 값만 쓴다. 출처 표시를 항상 붙인다.
- 위치는 그룹 드라이브 중(C3)과 핀할 때(D1)만 서버로 간다.
- 서버가 없을 때(1차 시연)는 커뮤니티 데이터를 "시연용"으로 표시한 내장 데이터로 보여 준다.
