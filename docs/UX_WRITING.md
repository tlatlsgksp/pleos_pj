# Moli UX 라이팅 기준

화면에 들어가는 모든 말(메뉴, 버튼, 알림, 안내, 오류)에 적용한다. 기획 문서의 설명 문장이 아니라 **사용자가 읽는 말**의 기준이다.

## 1. 원칙

1. **운전자가 쓰는 말로 쓴다.** 시스템이 하는 일이 아니라 사용자가 하는 일로 이름 짓는다. "위치 데이터 전송" ✕ → "위치 공유" ○
2. **짧게 쓴다.** 주행 중 보이는 문구는 한 줄, 12자 안쪽. 1초 안에 읽혀야 한다.
3. **해요체로 쓴다.** 높임은 한 번이면 된다. "~하실 수 있습니다" ✕ → "~할 수 있어요" ○
4. **결과를 말한다.** 버튼은 누르면 일어나는 일을 쓴다. "확인" 대신 "저장", "참여", "보내기".
5. **같은 것은 같은 이름으로 부른다.** 아래 용어집의 이름만 쓴다. 버튼이 "참여"면 알림도 "참여했어요".

## 2. 쓰지 않는 말

| 쓰지 않음 | 이유 | 이렇게 |
|---|---|---|
| ~되었습니다, 완료되었습니다 | 딱딱하고 길다 | 저장했어요, 보냈어요 |
| 진행하다, 진행 중입니다 | 무엇을 하는지 안 보인다 | 그룹 라이딩 중 |
| ~을 통해, ~에 대한, 해당, 및 | 번역투 | 문장을 나눠 쓴다 |
| 실패했습니다, 오류가 발생했습니다 | 원인과 할 일이 없다 | 연결이 끊겼어요. 다시 시도해 주세요 |
| 죄송합니다 | 사과는 정보가 아니다 | 무엇이 안 됐고 어떻게 하면 되는지만 |
| 정말 ~하시겠습니까? | 겁을 준다 | 그룹 라이딩에서 나갈까요? [나가기] [계속하기] |
| 영어 그대로 (Ranking, Report, Layer) | 차 안에서 읽기 어렵다 | 랭킹은 굳어진 말이라 예외, 나머지는 우리말 |
| 기능 설명 문장 ("~를 확인할 수 있어요") | 화면이 이미 보여 준다 | 쓰지 않는다 |
| 계산해서 만든 상태 문장 ("민수 1.2 km 앞") | 읽는 부담만 늘어난다 | 프로필, 아이콘 같은 익숙한 모양으로 |

## 3. 형식

- **제목, 메뉴, 버튼**: 명사나 짧은 동사로. 마침표 없음. "그룹 라이딩", "제보", "저장"
- **안내, 알림 문장**: 마침표를 찍는다. 한 문장이 기본, 많아야 두 문장.
- **숫자와 단위**: 숫자 뒤 한 칸 띄운다. "6.2 km/kWh", "1,460원"(원은 붙인다), "3분"
- **시간**: "방금", "5분 전", "어제", 그다음은 "11월 14일"
- **사람**: 이웃은 닉네임으로 부른다. "님"은 붙이지 않는다.

## 4. 상황별 문구 틀

| 상황 | 틀 | 예 |
|---|---|---|
| 끝난 일 | ~했어요 | 제보했어요 |
| 할 일 묻기 | ~할까요? + [동사] [다른 동사] | 그룹 라이딩에 참여할까요? [참여] [나중에] |
| 안 됨 | 무엇이 + 왜 + 어떻게 | 위치를 못 받았어요. 내비가 켜져 있는지 봐 주세요 |
| 비어 있음 | 아직 없음 + 할 수 있는 일 | 아직 이웃이 없어요. 아이디로 이웃을 추가해 보세요 |
| 주행 중 막힘 | 정차 중에 할 수 있어요 | 핀은 차를 세운 뒤 남길 수 있어요 |

## 5. 용어집

**확정**은 사용자가 정한 이름, **제안**은 이 문서가 고른 이름이다. 제안은 기획 담당이 확정한다.

### 메뉴

| 내부 이름 | 화면 이름 | 상태 | 메모 |
|---|---|---|---|
| Home | 홈 | 제안 | |
| 연비 리그 | 연비 랭킹 | 제안 | "리그"보다 바로 알아본다 |
| 지도 | 지도 | 제안 | |
| 나 | 내 정보 | 제안 | 아이콘 하나일 때는 "나"도 가능 |

## 6. 문구 예시 (주요 화면)

| 위치 | 문구 |
|---|---|
| 그룹 라이딩 초대 알림 | 민수의 그룹 라이딩에 참여할까요? [참여] [나중에] |
| 그룹 라이딩에서 나가기 | 확인 없이 바로 나간다. 토스트: "그룹 라이딩에서 나왔어요. 언제든 다시 참여할 수 있어요." |
| 위치 공유 안내 (참여 직전) | 그룹 라이딩 동안 이웃에게 내 위치가 보여요. |
| 제보 직후 | 사고를 제보했어요. |
| 내 경로 위 제보 배너 | 현재 경로 위에 사고 제보가 있어요 |
| 핀 장소 고르기 제목 | 어디에 핀을 남길까요? |
| 핀 장소 목록에 없을 때 | 목록에 없어요 (누르면 직접 입력) |
| 핀 남기기 (주행 중에 누름) | 핀은 차를 세운 뒤 남길 수 있어요. |
| 이웃이 없을 때 그룹 라이딩 | 같이 달릴 이웃이 없어요. 아이디로 이웃을 추가해 보세요. [이웃 추가] |
| 휴대폰 연결 | 휴대폰 카메라로 찍으면 Moli 앱이 열려요. |
| 주행 카드 | 큰 글자 "6.2 km/kWh", 아래 줄 "같은 차종 상위 12%" |
| 닉네임 변경 (주행 중에 누름) | 닉네임은 차를 세운 뒤 바꿀 수 있어요. |
| 연비 코치 꺼짐 | 연비 코치를 켜면 급가속할 때 무드등이 주황색으로 바뀌어요. [켜기] |
