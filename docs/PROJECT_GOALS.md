# Project Goals

## 목표

차량 데이터와 기능, 이동 상황을 활용해 운전자와 탑승자에게 새로운 경험을 주는 앱 서비스를 발굴하고 개발한다.

## 관점: 디지털 플랫폼으로서의 자동차

자동차는 이동 수단이면서 다양한 데이터와 기능을 제공하는 디지털 플랫폼이다. 앱이 활용할 수 있는 데이터는 다음과 같다.

- 위치
- 경로
- 주행 상태
- 차량 상태

이 데이터와 기능을 활용해 차량 환경에서 더 유용하게 쓸 수 있는 앱 서비스를 만든다.

## 서비스 발굴 범위

차량을 이용하는 순간은 다양하다. 다음 상황을 예로 들 수 있으며, 이에 한정하지 않고 고객의 이동 과정에서 필요한 서비스를 자유롭게 제안한다.

- 출퇴근
- 여행
- 충전
- 주차
- 가족과의 이동
- 반려동물 동반
- 휴식
- 업무
